# Bird-Species-Classification
Bird Species Classification using SNN_96x96
This project implements a **Bird Species Classification** model using a **Spiking Neural Network (SNN)** with PyTorch and snnTorch. The model classifies bird images from a dataset resized to **96×96 pixels** and demonstrates the application of neuromorphic deep learning for image classification.

## Features

- Bird image classification using Spiking Neural Networks (SNN)
- Built with PyTorch and snnTorch
- Image preprocessing (Resize 96×96, Normalization)
- Model training and evaluation
- GPU support with Google Colab
